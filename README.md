# QuickChat – PROG5121 Programming 1A POE Part 2

## 1. Project Overview

QuickChat is a Java console application developed for the PROG5121 Programming 1A Portfolio of Evidence (POE), Part 2. The application demonstrates basic messaging features and user input validation.

## 2. Features

* User registration and login.
* Username format validation.
* Password complexity validation.
* Cell phone number format validation.
* Creating and validating messages.
* Generating message IDs and message hashes.
* Sending, discarding, or storing messages.
* Displaying message information.
* Unit testing for selected message functions.
